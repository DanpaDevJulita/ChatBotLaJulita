Planes / paquetes

Estos son los domos o paquetes que el bot ofrece cuando un cliente pregunta por precios. Solo los que estén "Activo" se le muestran al bot. El bot cotiza SIEMPRE con estos valores, así que lo que se cambie acá es lo que el cliente va a recibir por WhatsApp. Un precio vacío significa "ese plan no se vende ese día" (por ejemplo un pasadía de domingo no tiene tarifa de entre semana).
